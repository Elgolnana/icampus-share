# icampus 트래커

> **비공식 개인 프로젝트입니다.** 성균관대학교와 관계없고, 아무것도 보증하지 않습니다(MIT 라이선스).
> 학교 사이트가 바뀌면 동작이 멈출 수 있습니다.

버튼 한 번이면 성균관대 icampus(Canvas)의 내 과목을 전부 확인합니다.

- 📝 **과제·퀴즈 마감**과 🎬 **안 본 온라인 강의**가 노션 표에 할 일로 올라옵니다
- 📢 **공지**도 노션에 원문 그대로 올라옵니다
- ✅ 과제를 제출하거나 강의를 다 보면 다음 실행 때 **자동으로 완료 체크**됩니다
- 📚 **교안·수업자료실·과제 첨부·게시판 첨부파일**이 내 컴퓨터 과목 폴더에 자동 저장됩니다

교수님마다 자료를 올리는 곳(강의콘텐츠, 수업자료실, 게시판, 과제 첨부…)이 달라도 전부 훑어서 과목별로 모아 줍니다.

## 준비물

- **Claude 유료 구독(Pro 이상)** + **Claude 데스크톱 앱**(Mac/윈도우, claude.ai/download)
  - Claude Code는 Pro 구독에 포함이라 추가 비용이 없습니다. 터미널을 몰라도 됩니다.
  - ⚠️ 웹사이트(claude.ai) 채팅으로는 안 됩니다. 내 컴퓨터에 교안을 저장하고 비밀번호를 내 키체인에 넣어야 해서 **데스크톱 앱의 코드 탭**이 필요합니다.
- Mac 또는 윈도우 10/11
- 성균관대 킹고ID, 노션 계정

## 설치

1. Claude 데스크톱 앱을 열고 왼쪽 위 **코드(`</>`)** 탭으로 갑니다.
2. 작업 폴더는 홈 폴더(Mac: `사용자이름` 폴더 / 윈도우: `C:\Users\사용자이름`)를 고릅니다.
3. 아래 한 줄을 그대로 붙여넣으세요.

```
https://github.com/Elgolnana/icampus-share 를 내 홈 폴더의 icampus-share에 clone하고, 그 안의 .claude/skills/icampus/SKILL.md를 읽고 설치 절차대로 진행해줘
```

Claude가 순서대로 물어보면서 설치합니다(10~20분). 토큰·비밀번호를 넣을 때는 화면에 **입력 창**이 따로 뜹니다. 채팅창에는 절대 붙여넣지 마세요. 끝나면 Dock(Mac) 또는 바탕화면(윈도우)에 **icampus 최신화** 버튼이 생깁니다.

## 사용

- 하루 한 번쯤 **icampus 최신화** 버튼을 누르면 됩니다. 실행 창에서 과목별 진행 상황이 보이고, 끝나면 요약이 나옵니다.
- 노션 표의 보기
  - **이번주 할 일**: 7일 안에 마감이고 아직 안 끝낸 과제·퀴즈·강의 (이번 주 / 다음 주 칸으로 나뉨. 노션 설정 → 언어 및 지역 → '주 시작: 월요일' 추천)
  - **놓친 것**: 마감이 지났는데 완료 체크가 안 된 것
  - **공지**: 아직 체크 안 한 공지
- 노션 표의 **열 이름(제목·강의·유형·날짜·링크·완료)은 바꾸지 마세요.** 보기 모양, 색, 순서, 보드·캘린더 전환은 자유입니다.

## 업데이트·문제 해결

Claude 데스크톱 앱 코드 탭에서 작업 폴더를 `icampus-share`로 열고 이렇게 말하세요.

- "아이캠 트래커 업데이트해줘"
- "아이캠 트래커 안 돼"
- "과목 폴더 바꿔줘", "이 과목은 빼줘"

## 보안: 비밀번호는 어디로 가나요?

- 킹고ID 비밀번호, Canvas 토큰, 노션 토큰은 **내 컴퓨터의 키체인**(Mac 키체인 / 윈도우 자격 증명 관리자)에만 저장됩니다.
- 입력은 화면에 뜨는 **시스템 입력 창**(Mac 입력창 / 윈도우 자격 증명 창)에 합니다. 값은 바로 키체인으로 들어가고 **Claude 대화에도, 파일에도 남지 않습니다.**
- 이 코드는 `canvas.skku.edu`, `icampus.skku.edu`, `api.notion.com` 말고는 어디에도 접속하지 않습니다. 코드는 전부 공개되어 있으니 직접 확인할 수 있습니다.
- 그만 쓰려면: Canvas 설정에서 토큰 삭제, 노션 통합 삭제, `icampus-share` 폴더 삭제.

## 하지 않는 것

- 강의 영상은 받지 않습니다.
- 자동 실행은 없습니다. 버튼을 눌렀을 때만 동작합니다.
- 받은 교안은 본인 공부용입니다. 다른 곳에 올리거나 나눠 주지 마세요.
