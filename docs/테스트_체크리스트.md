# 공개 전 테스트 체크리스트

테스터: **본인과 다른 과목을 듣는 친구**. 윈도우 1명 + Mac 1명이면 가장 좋다.
테스터는 README의 설치 한 줄만 받고 혼자 진행한다. 옆에서 도와주지 말고, 막힌 곳만 기록한다.

## 설치

- [ ] Claude Code가 저장소를 clone하고 SKILL.md를 읽었다
- [ ] (윈도우) `py`로 Python을 찾았다 / Store 가짜 python에 안 걸렸다
- [ ] `.venv` 생성, 패키지 설치, chromium 설치가 끝났다
- [ ] 질문이 Q1~Q4 + 과목 확인 외에 더 나오지 않았다
- [ ] 비밀값을 채팅으로 달라고 한 적이 **한 번도 없다**
- [ ] `set_secrets.py`를 자기 터미널에서 실행했다 (어디서 막혔는지 기록: ________)
- [ ] 노션 '연결' 단계에서 막혔는가? (예/아니오, 몇 번 다시 했는지: __)
- [ ] `doctor.py --login` 전부 OK
- [ ] 과목 스캔에 테스터의 이번 학기 과목이 전부 보였다
- [ ] 버튼이 생겼다 (Mac: Dock / 윈도우: 바탕화면)

## 첫 실행

- [ ] 버튼으로 실행 창이 떴고 과목별 진행이 보였다
- [ ] (윈도우) 한글이 깨지지 않았다
- [ ] 걸린 시간: ____분
- [ ] 노션 '이번주 할 일'에 실제로 다가오는 과제·퀴즈가 있다
- [ ] 노션 '이번주 할 일'에 안 본 온라인 강의가 있다 (온라인 강의가 있는 과목일 때)
- [ ] 노션 '공지'에 최근 공지가 있다
- [ ] 과목 폴더에 교안이 들어왔다. **Canvas에서 직접 본 자료와 비교해서 빠진 것:** ________
- [ ] (윈도우) 파일명에 특수문자가 있는 자료도 저장됐다
- [ ] 기존 폴더를 연결한 과목: 원래 파일이 그대로 있다
- [ ] 실행 요약에 "탭을 열었지만 내용을 읽지 못함"이 없다 (있으면 그 탭 이름 기록: ________)
- [ ] **GradeScope로 과제를 내는 과목이 있는가?** (예/아니오, 과목: ________) — 있으면 그 마감은 노션에 안 뜬다
